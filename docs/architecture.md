# 认证中心架构设计文档

## 1. 系统架构概述

### 1.1 架构原则
- **COLA架构模式**: 采用分层架构，清晰分离关注点
- **微服务架构**: 基于Spring Cloud Alibaba的分布式架构
- **多租户设计**: 支持数据隔离和资源隔离
- **安全优先**: 基于OAuth2.1和RBAC的安全体系

## 2. 微服务模块设计

### 2.1 服务模块划分

#### 2.1.1 auth-gateway (网关服务)
- **职责**: API网关、统一入口、安全拦截
- **技术**: Spring Cloud Gateway + Spring Security
- **功能**: 
  - 动态路由配置
  - JWT令牌验证
  - 请求限流熔断
  - 跨域处理
  - 请求日志记录

#### 2.1.2 auth-server (认证授权服务)
- **职责**: 用户认证、令牌管理、OAuth2.1协议
- **技术**: Spring Security OAuth2 + JWT
- **功能**:
  - 用户名密码登录
  - OAuth2.1授权码模式
  - JWT令牌签发/验证
  - 单点登录(SSO)
  - 令牌刷新机制

#### 2.1.3 user-service (用户管理服务)
- **职责**: 用户信息管理、多租户支持
- **技术**: Spring Boot + MyBatis Plus
- **功能**:
  - 用户CRUD操作
  - 用户状态管理
  - 多租户数据隔离
  - 用户信息查询

#### 2.1.4 role-service (角色权限服务)
- **职责**: RBAC权限管理、菜单权限控制
- **技术**: Spring Boot + MyBatis Plus
- **功能**:
  - 角色管理
  - 权限分配
  - 菜单管理
  - 权限验证

#### 2.1.5 client-service (客户端管理服务)
- **职责**: OAuth2客户端管理、应用管理
- **技术**: Spring Boot + MyBatis Plus
- **功能**:
  - 客户端注册
  - 客户端配置
  - 应用密钥管理
  - 回调地址管理

#### 2.1.6 log-service (日志服务)
- **职责**: 操作日志、审计日志记录
- **技术**: Spring Boot + Elasticsearch
- **功能**:
  - 操作日志记录
  - 登录日志记录
  - 审计日志查询
  - 日志统计分析

#### 2.1.7 monitor-service (监控服务)
- **职责**: 系统监控、健康检查、性能指标
- **技术**: Spring Boot Admin + Prometheus
- **功能**:
  - 服务健康监控
  - 性能指标收集
  - 告警通知
  - 系统状态展示

#### 2.1.8 file-service (文件存储服务)
- **职责**: 文件上传、下载、存储管理、大文件处理
- **技术**: Spring Boot + 对象存储SDK + 分片上传技术 + RocketMQ
- **功能**:
  - 多存储提供商支持（OSS、MinIO、S3、Google Cloud Storage）
  - 文件上传下载（支持大文件分片上传下载）
  - 断点续传功能
  - 文件元数据管理
  - 文件访问权限控制
  - 文件预览和缩略图生成
  - 存储空间管理和配额控制
  - 上传进度监控
  - 文件校验（MD5/SHA256）
  - 异步文件处理（通过消息队列）

#### 2.1.9 message-service (消息服务)
- **职责**: 消息队列管理、异步任务处理、事件驱动架构
- **技术**: Spring Boot + RocketMQ + Spring Cloud Stream
- **功能**:
  - 消息发布订阅
  - 异步任务处理
  - 事件驱动架构支持
  - 消息重试和死信队列
  - 消息轨迹追踪
  - 延迟消息支持
  - 顺序消息处理
  - 消息堆积监控

#### 2.1.10 notification-service (通知服务)
- **职责**: 邮件发送、短信发送、站内通知、多渠道通知管理
- **技术**: Spring Boot + Spring Mail + 短信服务商SDK + WebSocket
- **功能**:
  - 邮件模板管理
  - 短信模板管理
  - 多渠道通知发送
  - 通知状态跟踪
  - 通知模板变量替换
  - 通知发送限流
  - 通知发送失败重试
  - 实时站内通知推送

## 3. 数据流设计

### 3.1 用户登录流程
```
1. 用户访问前端登录页面
2. 前端调用/auth/oauth/token接口
3. 网关验证请求合法性
4. 认证服务验证用户凭证
5. 生成JWT令牌返回
6. 前端存储令牌并跳转
```

### 3.2 权限验证流程
```
1. 用户访问受保护资源
2. 网关验证JWT令牌有效性
3. 网关调用权限服务验证权限
4. 权限服务返回权限结果
5. 网关根据权限结果放行或拒绝
```

### 3.3 多租户数据隔离流程
```
1. 请求头携带租户ID
2. 网关解析租户ID
3. 服务层通过ThreadLocal传递租户ID
4. MyBatis拦截器自动添加租户过滤条件
5. 数据库查询自动隔离不同租户数据
```

## 4. 安全设计

### 4.1 认证机制
- **主要认证方式**: OAuth2.1授权码模式
- **辅助认证方式**: 密码模式、客户端模式
- **令牌类型**: JWT (JSON Web Token)
- **令牌有效期**: 访问令牌2小时，刷新令牌7天

### 4.2 权限控制
- **权限模型**: RBAC (基于角色的访问控制)
- **权限粒度**: 菜单级权限 + 操作级权限
- **权限验证**: 注解式权限控制 + 动态权限验证

### 4.3 安全防护
- **密码加密**: BCrypt加密存储
- **防暴力破解**: 登录失败次数限制
- **会话安全**: JWT无状态会话
- **CSRF防护**: 前后端分离架构天然防护
- **XSS防护**: 输入输出过滤

- **负载均衡**: Ribbon客户端负载均衡
